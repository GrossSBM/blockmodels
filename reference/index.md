# Package index

## Models for scalar networks

One value per dyad. The adjacency matrix may contain missing values
(NA).

- [`BM_bernoulli(`*`<new>`*`)`](https://grosssbm.github.io/blockmodels/reference/BM_bernoulli.md)
  : Perform estimation on blockmodels for bernoulli probability
  distribution
- [`BM_poisson(`*`<new>`*`)`](https://grosssbm.github.io/blockmodels/reference/BM_poisson.md)
  : Perform estimation on blockmodels for poisson probability
  distribution
- [`BM_gaussian(`*`<new>`*`)`](https://grosssbm.github.io/blockmodels/reference/BM_gaussian.md)
  : Perform estimation on blockmodels for gaussian probability
  distribution

## Models for multivariate networks

Several values per dyad (multiplex networks). Missing values are not
supported.

- [`BM_bernoulli_multiplex(`*`<new>`*`)`](https://grosssbm.github.io/blockmodels/reference/BM_bernoulli_multiplex.md)
  : Perform estimation on blockmodels for multiplex binary networks
- [`BM_gaussian_multivariate(`*`<new>`*`)`](https://grosssbm.github.io/blockmodels/reference/BM_gaussian_multivariate.md)
  : Perform estimation on blockmodels for multivariate gaussian
  probability distribution
- [`BM_gaussian_multivariate_independent(`*`<new>`*`)`](https://grosssbm.github.io/blockmodels/reference/BM_gaussian_multivariate_independent.md)
  : Perform estimation on blockmodels for multivariate independent
  homoscedastic gaussian probability distribution
- [`BM_gaussian_multivariate_independent_homoscedastic(`*`<new>`*`)`](https://grosssbm.github.io/blockmodels/reference/BM_gaussian_multivariate_independent_homoscedastic.md)
  : Perform estimation on blockmodels for multivariate independent
  homoscedastic gaussian probability distribution
